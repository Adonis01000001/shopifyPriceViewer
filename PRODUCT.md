# Product

## Register

product

## Users

Shopify merchants — solo store owners and small e-commerce teams who sell through Shopify and need to stay competitive on price. They're not pricing analysts; they're busy store owners who want clear, actionable data without complexity. They check the dashboard periodically (not continuously), want to see at a glance what needs attention, and trust the AI recommendations because they don't have time to do manual competitor analysis.

Context: often on a laptop, switching between Shopify admin and this tool. They need fast answers, not deep data exploration.

## Product Purpose

Full pricing intelligence for Shopify stores: monitor competitor prices automatically, get AI-powered recommendations, receive alerts when action is needed. The product replaces manual competitor price checking with an automated system that watches, analyzes, and recommends — so merchants can focus on selling instead of spreadsheets.

Success looks like: a merchant opens the dashboard, sees 3 products that need attention, reads the AI recommendation, and adjusts pricing in Shopify — all in under 5 minutes.

## Brand Personality

- **Calm** — never alarmist. Dense data presented with breathing room. No red banners everywhere.
- **Trustworthy** — confident recommendations with confidence scores. Shows its work. No black-box AI.
- **Clear** — every screen answers "what should I do now?" without requiring interpretation.

## Anti-references

- **SaaS-cream / generic startup** — no beige gradients, Inter font everywhere, cookie-cutter shadcn dashboards with identical card grids
- **Competitor-price-table clutter** — no walls of tiny text, no 50-row tables on a single screen
- **Crypto-hype dark mode** — no neon on black, no glitch effects, no overstimulating
- **Enterprise-bland** — no dense data tables, no gray-on-gray, no SAP-style interfaces
- **The hero-metric template** — no big number + small label + supporting stats + gradient accent on every landing page

## Design Principles

1. **Signal over noise** — if nothing needs attention, the dashboard should feel calm, not empty
2. **Confidence is part of the data** — always show how sure the system is (confidence scores, data source, last updated)
3. **One screen, one job** — each page has a clear primary action. No "everything everywhere" dashboards
4. **Monospace for numbers** — prices, scores, and metrics use tabular-nums for scanability
5. **Dark mode is the default** — this is a tool people check throughout the day; dark mode reduces eye strain

## Accessibility & Inclusion

- High readability: strong color contrast (WCAG AA minimum), readable body text (>=16px)
- Reduced motion: respect `prefers-reduced-motion`
- Keyboard-navigable: all interactive elements reachable and visible via Tab
- Color is never the only indicator: always pair with text, icons, or patterns
